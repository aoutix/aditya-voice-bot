How did you build this voice bot?
Three tiers, so it can't dead-end on you. Tier one is the Gemini Live API over a WebSocket — mic in, spoken audio out, with barge-in. If that can't start, tier two uses the browser's own speech recognition and synthesis around a text model. If there's no network, tier three answers from a prepared bank. The key bit is that the browser never holds the API key: a Cloudflare Worker proxies the socket and sends the setup frame itself, so the persona can't be swapped by editing the page's JavaScript. 90 words · #agents

Three projects I built

MCP-Hardener guards agent tools

Turns an OpenAPI spec into an MCP server an agent cannot misuse: read-only by default, writes held for a single-use approval.

Open the review console
TSpolicy.ts TSgateway.ts 10 rules 
export function guard(tool, args) {
  if (tool.read) return ok();
  const h = sha256(args);
  // one approval, one call
  return claim(tool.id, h);
}
Tenant ids never reach the agent.
